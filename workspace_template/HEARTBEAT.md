# Periodic Checks (HEARTBEAT.md)

The assistant reviews this checklist during periodic background checks (heartbeat).
If nothing requires the user's attention, respond with `HEARTBEAT_OK` only.

## Checklist
1. Check `MEMORY.md` and today's `memory/YYYY-MM-DD.md` for upcoming deadlines or reminders due right now.
2. If Google (Calendar / Gmail) or NocoDB MCP tools are connected and enabled by user preference, check for meetings in the next 2 hours or urgent unread messages.
3. Avoid sending unnecessary notifications at night (22:00–07:00 user timezone) unless truly critical.
