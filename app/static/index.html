Scheduler & Quick Actions

What do Heartbeat, Morning briefing & Nightly cleanup mean?
  • Heartbeat: Periodic silent background check (watches deadlines & messages per HEARTBEAT.md; notifies you only when something is urgent).
  • Morning briefing: Daily morning summary of your schedule, priorities, and open tasks (cron format, e.g. 0 8 * * * = daily at 8:00).
  • Nightly cleanup & reset: Saves important facts from today's chats into long-term memory at night and clears old context (saves tokens and keeps replies sharp).

Daily GitHub Agent Backup

Automatically pushes a sanitized snapshot of workspace memory, custom skills, scheduled tasks, and plugin/MCP configuration to GitHub.

Disabled
Use a private repository and a Fine-grained PAT with Contents: Read and write permission. Passwords, API keys, and OAuth tokens are never included in backups.
Step-by-step setup guide for GitHub backup (2 minutes)
  1. 1
    Create a Private repository on GitHub
    Pick a name (e.g. assistant-backup), set visibility to Private, and click Create repository. An empty repository is fine — the first backup creates the main branch automatically.
    Open GitHub New Repository
  2. 2
    Create a Fine-grained Personal Access Token (PAT)
    Give the token a name (e.g. Assistant Backup), pick an Expiration, and under Repository access select “Only select repositories” → choose your new private backup repository.
    Open GitHub Fine-grained Tokens
  3. 3
    Grant Contents: Read and write permission
    Expand Permissions → Repository permissions, find Contents, and set it to Read and write (Metadata is enabled automatically). Click Generate token and copy the github_pat_… token right away.
  4. 4
    Fill in the form above, save, and test
    Enter your-user/assistant-backup (or full HTTPS URL) into GitHub repository, paste the token, turn the switch on, click “Save backup settings”, and then “Back up now”.

How to finish connecting (takes 10 seconds)
Because the assistant runs on a server, the browser cannot reach localhost (127.0.0.1) on your PC. That error page actually means Google approved access.
  1. 1
    Sign in and allow access
    Click the button above, pick your account, and approve the requested permissions.
  2. 2
    Expect the “127.0.0.1 refused to connect” page
    Do not close that browser tab! Even though it looks like an error, the login token is inside its address bar.
  3. 3
    Copy the full address from the browser bar
    Click the address bar (or press Ctrl+L / Cmd+L) and copy the entire URL (Ctrl+C / Cmd+C).
    http://127.0.0.1:12345/callback?state=…&code=4/0A… Copy whole URL
  4. 4
    Return here and paste
    Click “Paste from clipboard” below or press Ctrl+V / Cmd+V anywhere in this window — connection finishes automatically.
