# Ranný briefing

Tento postup použi, keď máš pripraviť ranný briefing alebo denný súhrn.

## Kroky
1. Prečítaj `USER.md`, `MEMORY.md` a včerajšiu poznámku v `memory/` (ak existuje).
2. Over, ktoré MCP nástroje sú momentálne dostupné:
   - Ak je dostupný Kalendár / Gmail, vypíš dnešné udalosti a dôležité neprečítané správy.
   - Ak sú dostupné prehľady úloh / databázy (napr. NocoDB, CRM, task tracker), zhrň dnešné priority.
3. Vytvor stručný prehľad s týmito sekciami:
   - **Dnešný program** (udalosti chronologicky)
   - **Priority & otvorené úlohy** (max. 5 kľúčových položiek)
   - **Vyžaduje pozornosť** (urgentné správy alebo termíny, ak nejaké sú)
4. Drž text krátky a dobre čitateľný na mobile (Telegram).
