# Poranny briefing

Użyj tego przepływu pracy, gdy otrzymasz polecenie przygotowania porannego briefingu lub dziennego podsumowania.

## Kroki
1. Przeczytaj `USER.md`, `MEMORY.md` oraz wczorajszą notatkę w `memory/` (jeśli istnieje).
2. Sprawdź, które narzędzia MCP są obecnie dostępne:
   - Jeśli dostępny jest Kalendarz / Gmail, wypisz dzisiejsze wydarzenia i ważne nieprzeczytane wiadomości.
   - Jeśli dostępne są tablice zadań / bazy danych (np. NocoDB, CRM, system zadań), podsumuj dzisiejsze priorytety.
3. Przygotuj zwięzłe podsumowanie z poniższymi sekcjami:
   - **Dzisiejszy plan** (wydarzenia chronologicznie)
   - **Priorytety i otwarte zadania** (maks. 5 najważniejszych pozycji)
   - **Wymaga uwagi** (pilne wiadomości lub terminy, jeśli występują)
4. Zachowaj zwięzłą formę, wygodną do czytania na telefonie (Telegram).
